# Photo / sketch input guide

Best → worst input: dimensioned hand sketch > straight-on photo with ruler in the same plane > angled photo > no reference.

Taking a usable photo
- Straight on (camera parallel to the face), from 40+ cm with zoom, not close wide-angle (lens distortion).
- Ruler, credit card (85.6 x 54 mm) or coin beside the part, **same plane/height as the feature to measure**.
- Plain contrasting background; one photo per face; a side shot for thickness/depth.
- Photo the mating object too (the rod, the frame lip, the shaft), not only the thing to copy.

What a photo can/cannot give
- Can: shape, feature layout, what mates with what. Error ≈ ±1–2 mm with reference, unbounded without.
- Cannot: hidden faces, thickness, tolerances, hole diameters that must fit something → measure with calipers.

Agent rules: all photo-derived sizes are `UNVERIFIED ±err`; fit-critical ones go through a fit gauge first.
